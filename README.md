# Skopelos Guide Mobile App

A cross-platform mobile application developed during my internship at Ontovisual as part of the Skopelos Guide project.

The application provides a mobile-friendly digital guide experience for Android and iOS, integrating authentication, dynamic content and map-based functionality.

## Features

- User authentication with Firebase Authentication
- Interactive maps using Leaflet
- Integration with REST APIs
- Dynamic content presentation
- Cross-platform functionality for Android and iOS
- Mobile-friendly user interface

## Technologies

- React Native
- JavaScript
- Firebase Authentication
- REST APIs
- Leaflet
